# Content; intent, evidence, information gain

## The brief (every page starts here)

| Field | Content |
|---|---|
| Primary intent | one of informational / commercial / transactional / navigational |
| Target query set | head + modifiers, from GSC + SERP evidence |
| Format | whatever the current SERP rewards (table/tool/list/guide) |
| Entities | named entities the page must cover (the topic graph) |
| Proof | the first-hand evidence, data, or testing that makes this page true |
| Passage targets | the questions it must answer directly (40–60 words each) |

## E-E-A-T is evidence, not adjectives

- **Experience**: first-hand testing, photos, batch numbers, real
  numbers from real operations.
- **Expertise**: named authors with credentials reachable in one click.
- **Authoritativeness**: cited by others in the niche (links back to
  the authority pillar).
- **Trust**: honest dates, sources cited, disclaimers where stakes are
  high, no claims the operation cannot back.

YMYL queries (health, finance, safety; including research-chemical
safety content) are judged at the highest evidence bar.

## Information gain

Google's stated preference. A page earns rank when it adds something
the existing results lack: original data, first-hand testing, a better
format, a missing subtopic, a sharper answer. Rewriting the SERP adds
nothing and earns nothing.

## Pruning

Quarterly: pages with no impressions, no links, and no conversion after
two cycles get consolidated (merge into the nearest strong page, 301)
or `410`. Site-wide quality is a ranking input; thin pages are a tax
every strong page pays.
